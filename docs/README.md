# Screenshots

Place these two images in this folder:

- `screenshot-code-review.png` — The code review result page showing score 25 and three critical issue cards
- `screenshot-research.png` — The research report page showing the headline and Literature tab with real PMIDs

To take them:
1. Run `npm run dev`
2. Open `http://localhost:3000/dashboard/code-review`
3. Paste the RNA-seq test script and click "Review my code"
4. Take a full-screen screenshot
5. Save as `docs/screenshot-code-review.png`

Repeat for the research page.

Do NOT commit screenshots containing your email, Supabase URL, or any secret.
